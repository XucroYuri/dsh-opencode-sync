# dsh-opencode-sync API

## CLI

```bash
dsh-opencode-sync [--dry-run] [--source windows|wsl|auto] [--dsh-home PATH]
```

## Options

| Option | Description |
|---|---|
| `--dry-run` | Print changes without writing |
| `--source` | OpenCode config source |
| `--dsh-home` | DSH home directory, default `~/.dsh` |
